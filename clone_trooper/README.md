# Clone trooper 3D (style 501e légion)

Modèle 3D low-poly généré par `generate_clone.py` (Python + trimesh), d'après l'image de référence.

| Fichier | Usage |
|---|---|
| `clone_trooper.glb` | Modèle en couleurs (blanc / bleu / noir) — Blender, Windows Visionneuse 3D, https://gltf-viewer.donmccurdy.com |
| `clone_trooper.obj` | Format universel (Blender, Maya, 3ds Max…) |
| `clone_trooper.stl` | Impression 3D (hauteur ≈ 300 mm, à redimensionner dans le slicer) |
| `apercu.png` | Aperçu face / 3/4 / dos |

Régénérer : `pip install trimesh scipy && python3 generate_clone.py`
