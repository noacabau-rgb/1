# Serpent Émeraude — logo 3D

- `index.html` — scène 3D interactive (Three.js) : glisser pour tourner, molette pour zoomer.
  - `?still` : image fixe, sans animation · `?still&transparent` : fond transparent.
- `logo-serpent.png` — rendu 2048×2048 avec fond.
- `logo-serpent-transparent.png` — rendu 2048×2048, fond transparent.
