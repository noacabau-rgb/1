# Luke – modèle 3D stylisé

- `luke.glb` : modèle en couleurs (ouvrable dans Blender, Windows Visionneuse 3D, https://gltf-viewer.donmccurdy.com)
- `luke.obj` : format universel
- `luke.stl` : pour l'impression 3D
- `build_luke.py` : script qui génère le modèle (`pip install trimesh numpy scipy && python3 build_luke.py`)

Hauteur : 1,75 m (mettre à l'échelle dans le slicer pour une figurine).
